## ⚡ How to Use

1. Pick a topic from the folders above.
2. Open a problem directory.
3. Read the problem statement in `README.md`.
4. Study the implementation in `solution.*`.
5. Practice by re-implementing from scratch.

## 🔄 Auto Sync Workflow

This repository includes a GitHub Actions workflow that can sync LeetCode submissions and auto-organize them into topic folders.

- Workflow file: [`/.github/workflows/sync_leetcode.yml`](./.github/workflows/sync_leetcode.yml)
- Triggered by:
  - Manual dispatch
  - Weekly schedule
